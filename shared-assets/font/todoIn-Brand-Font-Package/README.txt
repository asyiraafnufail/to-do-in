todoIn Brand Font — v1.0

Files:
- todoIn-Brand.ttf — installable TTF font.
- todoIn-Brand-preview.png — preview.

IMPORTANT:
This is a custom brand-font prototype built from the locked todoIn lettering reference.
The exact logo wordmark is implemented as a ligature for the text sequence "todoIn".
The rest of the alphabet uses a rounded display base so the font remains usable for supporting text.

In Illustrator/Photoshop:
1. Install todoIn-Brand.ttf.
2. Type: todoIn
3. Keep Standard Ligatures enabled if your app exposes that setting.
4. The logo-style wordmark will appear for "todoIn".

Note: Fonts are monochrome by nature. The green/white split from the logo is not embedded as font color; for the official colored logo, use the locked vector logo asset.
